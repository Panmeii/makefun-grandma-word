One word for **One Word From Grandma** on make.fun: `UNPLUGIT` — the single word a grandma would text about AI, in her full caps-lock voice: her universal fix for any machine that gets ideas above its station is to unplug it. The Node program (`main.ts`) writes the word to `entry.txt` in the output directory, then verifies it against the competition gate — UTF-8 text of 1 to 30 characters, not only whitespace, exactly one word with no spaces or punctuation tricks — and exits non-zero if any check fails.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
